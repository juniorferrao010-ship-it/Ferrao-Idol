# Idol Ferrão — Portfólio

Site estático (HTML + CSS), pronto para GitHub Pages. Todos os ficheiros estão na mesma pasta.

## Publicar
1. Cria um repositório no GitHub (ex.: `idol-ferrao`).
2. Envia TODOS os ficheiros desta pasta para a raiz do repositório (inclui `.nojekyll`).
3. Em **Settings → Pages → Build and deployment**: *Source* = `Deploy from a branch`, *Branch* = `main`, pasta `/ (root)`. Guarda.
4. Após ~1 minuto: `https://<utilizador>.github.io/<repositório>/`.
